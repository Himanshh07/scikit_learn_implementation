This repository contains hands-on implementations of various machine learning algorithms using Scikit-learn, one of the most powerful and widely-used machine learning libraries in Python. The project is aimed at helping beginners understand the practical application of scikit-learn for building, training, and evaluating machine learning models.
And working on House price dataset from the kaggle.
It covers the complete machine learning pipeline including:
- Data preprocessing and feature scaling
- Model selection and training
  
Algorithms Implemented
- Linear Regression
  
Technologies Used
-Python
-Scikit-learn
-Pandas
-NumPy
-Matplotlib (for visualization)
-Jupyter Notebook
